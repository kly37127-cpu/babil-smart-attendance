# Babil Smart Attendance — النسخة التجريبية

## تشغيل الموقع
1. فك ضغط الملف.
2. افتح `index.html` بمتصفح حديث (Chrome مثلاً).
3. اسمح للموقع باستخدام GPS عند طلب ذلك.
4. لوحة الإدارة: الرمز التجريبي `2468`.

## نشر مجاني عبر GitHub Pages
1. أنشئ حساباً في https://github.com إذا لم يكن لديك حساب.
2. أنشئ مستودعاً جديداً باسم `babil-smart-attendance`.
3. ارفع ملف `index.html` إلى المستودع.
4. افتح Settings ثم Pages.
5. اختر Deploy from a branch، ثم `main` و`/ (root)`، واضغط Save.
6. انتظر ظهور رابط الموقع في صفحة Pages.

## مهم جداً — حدود هذه النسخة
هذه نسخة أولية للعرض والتجربة وليست نظاماً إنتاجياً آمناً:
- البيانات محفوظة في المتصفح على نفس الجهاز فقط؛ لا تتشارك الأجهزة سجلاتها.
- رمز الإدارة التجريبي ظاهر داخل الكود وهو ليس حماية حقيقية.
- فحص GPS يتم في المتصفح ويمكن التلاعب به؛ يحتاج تحققاً من جهة الخادم.
- البصمة/Passkey الحقيقية تحتاج WebAuthn مع خادم يصدر ويتحقق من التحديات.
- لا يوجد حالياً حسابات موظفين أو قاعدة بيانات مشتركة أو تقارير غياب معتمدة.

لتحويلها إلى نظام فعلي متعدد الموظفين نربط الواجهة بقاعدة بيانات وخادم مجاني (مثل Supabase) ونضيف تحققاً آمناً للموقع والبصمة.
